# Транскрибатор

Локальное приложение превращает запись звонка на русском языке в транскрипт с замаскированными персональными
данными. Потом оно возвращает оригиналы в ответ, полученный от Claude. Распознавание, маскирование и
демаскирование выполняются только на компьютере пользователя. Наружу уходит лишь замаскированный docx.

## Установка

macOS (Apple Silicon) и Linux:

```bash
curl -fsSL <домен>/install.sh | bash
```

Windows 10/11:

```powershell
powershell -ExecutionPolicy ByPass -c "irm <домен>/install.ps1 | iex"
```

Скрипт ставит uv, приложение и модели (около 300 МБ, с проверкой SHA-256), создаёт значок и открывает
приложение. Права администратора не нужны, повторный запуск безопасен. Источник пакета задаётся переменной
`TRANSCRIBER_SOURCE` (по умолчанию — git-репозиторий), зеркало моделей — `TRANSCRIBER_MODELS_MIRROR`.

Удаление: `install/uninstall.sh`. Скрипт спрашивает, удалять ли данные дел.

## Работа

1. Клик по значку поднимает сервер на `127.0.0.1:7860` и открывает вкладку браузера. Повторный клик только
   открывает вкладку.
2. При первом запуске задаётся пароль. Им шифруются словари соответствий и транскрипты. Пароль восстановить
   нельзя.
3. Создайте дело и перетащите запись (mp3, m4a, wav, ogg, opus, flac, webm) или готовый транскрипт
   (txt, md, docx, srt, vtt). Вкладку можно закрыть, обработка продолжится.
4. На экране проверки снимите ложные маски кликом, добавьте пропущенные выделением, объедините варианты
   одной сущности и отметьте «Я проверил». После этого станет доступен экспорт.
5. docx сохраняется в «Загрузки» как `<код дела>_транскрипт.docx`. Загрузите его в Claude.
6. Ответ Claude вставьте во вкладку «Вернуть данные». Дело определяется по коду в тексте.

## Командная строка

```bash
transcriber transcribe call.m4a -o call.txt
```

```bash
transcriber mask call.m4a --vault vault.json -o DEL-0001_транскрипт.docx
```

```bash
transcriber unmask answer.md --vault vault.json -o answer_restored.md
```

```bash
transcriber eval dataset.jsonl --answers answers.jsonl
```

```bash
transcriber models download
```

`vault.json` в CLI хранится открытым текстом и содержит ПД. Этот режим нужен для автотестов и замеров
качества. В приложении словари лежат только в зашифрованной базе.

## Как устроено

| Шаг | Реализация |
|---|---|
| Декодирование | PyAV (ffmpeg внутри колёс), ресемплинг в 16 кГц |
| Распознавание | GigaAM v3 `e2e_rnnt` int8 через onnx-asr, нарезка Silero VAD до 30 с; T-one — опция |
| Диаризация | Стерео с разными каналами — по каналам, с подавлением эха. Моно — sherpa-onnx (pyannote segmentation 3.0 и 3D-Speaker CAM++) в отдельном процессе |
| Числа словами | Собственный нормализатор на pymorphy3 («восемь девятьсот шестнадцать» → «8 916») |
| Форматные ПД | Regex с контрольными суммами (Луна, СНИЛС, ИНН) по склеенным репликам спикера: номер, продиктованный с перебивкой, находится целиком |
| Имена и организации | slovnet NER и словарь имён pymorphy3; падеж и пол — морфология slovnet по контексту |
| Демаскирование | Толерантный парсер меток, склонение pymorphy3 и правила для фамилий, падеж по предлогу или глаголу для меток без падежа |
| Хранилище | SQLite, каждая запись зашифрована AES-256-GCM, ключ из пароля через Argon2id |
| Интерфейс | FastAPI и статический интерфейс без CDN |

Сеть после установки не используется. В коде выставлены `HF_HUB_OFFLINE=1`, а модели берутся только из
локального каталога. Сервер слушает `127.0.0.1`, проверяет заголовок Host и требует сессионную cookie и
заголовок `X-Requested-With`, поэтому чужие страницы в браузере не могут отправить ему команды. Проверка
обновлений выполняется только по кнопке и только если задан `TRANSCRIBER_UPDATE_URL`.

### Скорость

Замер на Windows-ПК с 12 логическими ядрами: 10 минут моно-записи обрабатываются за 121 с, это около 12 минут
на час. Распознавание и диаризация идут параллельно, ядра делятся пополам. Детекция ПД на часовом объёме
текста занимает около 3 с, демаскирование ответа на 20 тыс. символов — меньше 0,1 с. Цель ТЗ — 10 минут на
M1 с 8 ГБ — нужно проверить на целевом маке. Число потоков задаётся переменными `TRANSCRIBER_ASR_THREADS` и
`TRANSCRIBER_DIAR_THREADS`, порог кластеризации голосов — `TRANSCRIBER_DIAR_THRESHOLD` (по умолчанию 0,6;
подбирается на тестовом наборе).

### Отличия от ТЗ

- **FastAPI вместо Gradio.** В Gradio нельзя штатно снимать маску кликом и добавлять её выделением текста, а
  фоновые задачи привязаны к сессии вкладки.
- **Шифрование записей вместо SQLCipher.** У SQLCipher нет надёжных колёс под все целевые платформы.
  Открытым текстом лежат только идентификаторы, коды дел и время.
- **Маска телефона `+7 000 000-NN-NN`.** Она даёт до 9999 номеров на дело вместо 99. Маски телефонов и
  email внесены в белый список детектора, поэтому повторное маскирование ничего не находит.
- **Номер в нескольких репликах.** Если номер продиктован в двух репликах, метка ставится в первой, а
  продолжение заменяется на `[…]`.
- **Модель сегментации.** Используется pyannote segmentation 3.0 (MIT) в сборке sherpa-onnx, а не
  community-1 (CC-BY-4.0).

## Разработка

```bash
uv sync
```

```bash
uv run pytest
```

```bash
uv run transcriber serve
```

Для медленных тестов с моделями задайте `TRANSCRIBER_MODELS` или положите модели в `.devdata/models`.
Реальный тестовый набор звонков хранится вне репозитория.

## Правовая рамка

Метки при наличии словаря соответствий — псевдонимизация, а не обезличивание по 152-ФЗ. Передача
замаскированного текста зарубежному сервису остаётся трансграничной передачей. Приложение — техническая мера
минимизации ПД, передаваемых внешнему обработчику. Итоговое заключение даёт юрист. Лицензии компонентов
перечислены в [NOTICE](NOTICE).
