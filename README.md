# Транскрибатор

Программа превращает запись звонка в текст и прячет в нём персональные данные: имена, телефоны, номера карт,
адреса и всё похожее. Такой текст можно спокойно загрузить в Claude и попросить его проанализировать звонок.
Когда Claude ответит, программа вернёт в его ответ настоящие имена и номера.

Всё работает на вашем компьютере. Запись и настоящие данные никуда не отправляются. Наружу уходит только
файл, в котором вместо «Петров Иван» написано `[ФИО_1:им]`, а вместо телефона — `+7 000 000-00-01`.

## Установка

Понадобится интернет (только на время установки), около 2 ГБ свободного места и 8 ГБ оперативной памяти.
Права администратора не нужны.

### Windows 10 и 11

1. Нажмите «Пуск», наберите `PowerShell` и откройте его.
2. Скопируйте команду, вставьте в окно PowerShell и нажмите Enter:

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://raw.githubusercontent.com/sVerentsov/local_asr_and_masking/main/install/install.ps1 | iex"
```

3. Подождите 5–10 минут: программа скачает всё нужное и сама откроется в браузере.

Потом программу можно запускать из меню «Пуск» → «Транскрибатор».

### Mac (на процессоре M1 и новее)

1. Откройте «Терминал» (Программы → Утилиты → Терминал).
2. Скопируйте команду, вставьте и нажмите Enter:

```bash
curl -fsSL https://raw.githubusercontent.com/sVerentsov/local_asr_and_masking/main/install/install.sh | bash
```

3. Подождите 5–10 минут: программа откроется в браузере.

Потом программу можно запускать из папки «Программы» → «Транскрибатор».

## Как пользоваться

**Первый запуск.** Программа попросит придумать пароль. Им защищены ваши дела и настоящие данные из звонков.
Запишите пароль в надёжное место: восстановить его нельзя. Без пароля нельзя будет вернуть настоящие данные
в ответы Claude.

**1. Создайте дело.** Дело — это папка для звонков по одной теме, например «Клиент Ромашка». Внутри дела
один и тот же человек во всех звонках получает одну и ту же метку.

**2. Перетащите запись звонка** в окно программы. Подойдут файлы mp3, m4a, wav, ogg, opus, flac, webm. Если
текст звонка уже есть, перетащите его: txt, docx, md, srt или vtt. Можно указать, сколько людей было в
разговоре, или оставить «авто». Вкладку браузера можно закрыть, программа доработает сама.

**3. Проверьте маски.** Это самый важный шаг: программа может ошибиться.
- Цветом выделено то, что будет спрятано. Нажмите на выделение, чтобы убрать маску, если она лишняя.
- Выделите мышью текст, который программа пропустила, и выберите, что это (ФИО, телефон и т. д.).
- Если одного человека программа записала двумя разными людьми, отметьте обоих в списке справа и нажмите
  «Объединить».
- Подпишите собеседников ролями: «Оператор», «Клиент». Имена в подписях не нужны, они всё равно будут
  спрятаны.
- Когда всё проверено, поставьте галочку «Я проверил маски».

**4. Скачайте файл.** Нажмите «Скачать DOCX». Файл появится в папке «Загрузки» с именем вида
`DEL-7F3A_транскрипт.docx`. В имени файла только код дела, без имён.

**5. Загрузите файл в Claude** и задайте вопросы. В начале файла уже есть подсказка для Claude, как обращаться
с метками.

**6. Верните настоящие данные.** Скопируйте ответ Claude, откройте вкладку «Вернуть данные», вставьте ответ
и нажмите кнопку. Программа сама узнает дело по коду и подставит имена в нужном падеже: «передайте
`[ФИО_1:дат]`» превратится в «передайте Петрову Ивану». Зелёным выделено то, что восстановлено. Красным —
метки, которых программа не знает: скорее всего, Claude их придумал.

### Частые вопросы

**Куда-то отправляются мои записи?** Нет. Распознавание и поиск данных выполняются на вашем компьютере.
В интернет программа ходит только при установке и при нажатии «Проверить обновления».

**Где хранятся данные?** В зашифрованной базе на вашем компьютере: на Windows в `%LOCALAPPDATA%\transcriber`,
на Mac в `~/Library/Application Support/transcriber`. Сама запись звонка после обработки не хранится. Дела
удаляются автоматически через 30 дней без изменений, срок меняется в настройках.

**Сколько ждать?** Примерно 12–15 минут на час записи, зависит от компьютера.

**Как выключить программу?** Кнопка «Выключить» в правом верхнем углу.

**Как удалить программу?**
- Windows: в PowerShell выполните `uv tool uninstall transcriber`, удалите ярлык «Транскрибатор» из меню
  «Пуск» и, если дела больше не нужны, папку `%LOCALAPPDATA%\transcriber`.
- Mac: в Терминале выполните команду ниже. Она спросит, удалять ли дела.

```bash
curl -fsSL https://raw.githubusercontent.com/sVerentsov/local_asr_and_masking/main/install/uninstall.sh | bash
```

**Это обезличивание по закону?** Нет. Пока у вас есть словарь с настоящими данными, это псевдонимизация, а не
обезличивание по 152-ФЗ. Передача текста зарубежному сервису остаётся трансграничной передачей. Программа
уменьшает объём персональных данных, которые видит Claude, но юридическую оценку даёт юрист.

## Для разработчиков

### Командная строка

```bash
transcriber transcribe call.m4a -o call.txt
```

```bash
transcriber mask call.m4a --vault vault.json -o DEL-0001_транскрипт.docx
```

```bash
transcriber unmask answer.md --vault vault.json -o answer_restored.md
```

```bash
transcriber eval dataset.jsonl --answers answers.jsonl
```

```bash
transcriber models download
```

`vault.json` в CLI хранится открытым текстом и содержит ПД. Этот режим нужен для автотестов и замеров
качества. В приложении словари лежат только в зашифрованной базе.

Установщики можно направить на другой источник пакета (`TRANSCRIBER_SOURCE`) и на зеркало моделей
(`TRANSCRIBER_MODELS_MIRROR`). Модели сверяются по SHA-256 из `src/transcriber/models.lock.json`.

### Как устроено

| Шаг | Реализация |
|---|---|
| Декодирование | PyAV (ffmpeg внутри колёс), ресемплинг в 16 кГц |
| Распознавание | GigaAM v3 `e2e_rnnt` int8 через onnx-asr, нарезка Silero VAD до 30 с; T-one — опция |
| Диаризация | Стерео с разными каналами — по каналам, с подавлением эха. Моно — sherpa-onnx (pyannote segmentation 3.0 и 3D-Speaker CAM++) в отдельном процессе |
| Числа словами | Собственный нормализатор на pymorphy3 («восемь девятьсот шестнадцать» → «8 916») |
| Форматные ПД | Regex с контрольными суммами (Луна, СНИЛС, ИНН) по склеенным репликам спикера: номер, продиктованный с перебивкой, находится целиком |
| Имена и организации | slovnet NER и словарь имён pymorphy3; падеж и пол — морфология slovnet по контексту |
| Демаскирование | Толерантный парсер меток, склонение pymorphy3 и правила для фамилий, падеж по предлогу или глаголу для меток без падежа |
| Хранилище | SQLite, каждая запись зашифрована AES-256-GCM, ключ из пароля через Argon2id |
| Интерфейс | FastAPI и статический интерфейс без CDN |

Сеть после установки не используется. В коде выставлены `HF_HUB_OFFLINE=1`, а модели берутся только из
локального каталога. Сервер слушает `127.0.0.1`, проверяет заголовок Host и требует сессионную cookie и
заголовок `X-Requested-With`, поэтому чужие страницы в браузере не могут отправить ему команды. Проверка
обновлений выполняется только по кнопке и только если задан `TRANSCRIBER_UPDATE_URL`.

### Скорость

Замер на Windows-ПК с 12 логическими ядрами: 10 минут моно-записи обрабатываются за 121 с, это около 12 минут
на час. Распознавание и диаризация идут параллельно, ядра делятся пополам. Детекция ПД на часовом объёме
текста занимает около 3 с, демаскирование ответа на 20 тыс. символов — меньше 0,1 с. Цель ТЗ — 10 минут на
M1 с 8 ГБ — нужно проверить на целевом маке. Число потоков задаётся переменными `TRANSCRIBER_ASR_THREADS` и
`TRANSCRIBER_DIAR_THREADS`, порог кластеризации голосов — `TRANSCRIBER_DIAR_THRESHOLD` (по умолчанию 0,6;
подбирается на тестовом наборе).

### Отличия от ТЗ

- **FastAPI вместо Gradio.** В Gradio нельзя штатно снимать маску кликом и добавлять её выделением текста, а
  фоновые задачи привязаны к сессии вкладки.
- **Шифрование записей вместо SQLCipher.** У SQLCipher нет надёжных колёс под все целевые платформы.
  Открытым текстом лежат только идентификаторы, коды дел и время.
- **Маска телефона `+7 000 000-NN-NN`.** Она даёт до 9999 номеров на дело вместо 99. Маски телефонов и
  email внесены в белый список детектора, поэтому повторное маскирование ничего не находит.
- **Номер в нескольких репликах.** Если номер продиктован в двух репликах, метка ставится в первой, а
  продолжение заменяется на `[…]`.
- **Модель сегментации.** Используется pyannote segmentation 3.0 (MIT) в сборке sherpa-onnx, а не
  community-1 (CC-BY-4.0).
